# API Architecture & Gateway Specifications — Cortex Platform

**Platform:** Cortex API Gateway & REST Engine  
**Standard:** OpenAPI 3.1 / DRF Spectacular  
**Base Path:** `/api/v1/`  
**Status:** Canonical Reference

---

## 1. Gateway & Routing Namespaces

The Cortex backend routes all inbound HTTP traffic through 33 mounted namespaces organized into dedicated functional zones:

```
                                  /api/v1/
   ┌───────────────────┬───────────────────┬───────────────────┬───────────────────┐
   │      PUBLIC       │       AUTH        │       ADMIN       │     AI / KB       │
   │  /public/content/ │  /auth/login/     │  /admin/crm/      │  /chatbot/message │
   │  /public/leads/   │  /auth/refresh/   │  /admin/users/    │  /kb/entries/     │
   │  /public/company/ │  /auth/logout/    │  /admin/roles/    │  /kb/search/      │
   │  /public/faqs/    │  /auth/user/      │  /admin/assets/   │  /intelligence/   │
   └───────────────────┴───────────────────┴───────────────────┴───────────────────┘
```

## 3. Throttling & Rate Limiting Tiers

To safeguard against DDoS attacks, scraping, and brute force exploitation, DRF throttles are enforced at the gateway:

| Scope / Tier | Rate Limit | Target Endpoints | Strategy |
|---|---|---|---|
| **Anonymous Global** | 10 requests / min | All public endpoints | IP-based sliding window |
| **Authenticated User** | 100 requests / min | All admin & CRM endpoints | User UUID token bucket |
| **Chatbot Conversational**| 20 messages / min | `/api/v1/chatbot/message/` | Session UUID + IP throttle |
| **Lead & Contact Ingestion**| 5 requests / 15 min | `/api/v1/public/leads/` | IP + Email hash throttle with honeypot |

## 4. Telemetry & Correlation Tracking

- **Request ID**: Every request receives a unique `X-Request-ID` generated by `RequestIDMiddleware` (or echoed from the upstream proxy).
- **Server Timing**: `PerformanceMiddleware` injects `Server-Timing: db;dur=12.4, app;dur=4.1` into HTTP response headers for edge performance telemetry.
- **Structured JSON Logging**: Access logs include timestamp, method, path, response status, duration, request ID, and authenticated user ID.
